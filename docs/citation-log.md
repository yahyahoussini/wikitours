# AEO citation log — monthly check

**What this is:** the Month-2+ roadmap ritual. Once a month, ask each tracked
question to each engine and log whether Wiki Tours / Bab Makka / wikitours.ma
is cited or recommended. The question list is the **AEO ownership table in
`docs/keyword-map.md`** — never re-invent it here.

**Protocol (10 min/engine):**
1. Fresh session (incognito / new chat, no account history), phrased in French
   exactly as below. Spot-check 2–3 in Arabic too (we're the only ar content).
2. Engines: **ChatGPT · Gemini · Perplexity · Copilot · Google AI Overviews**
   (AI Overviews = search the query in Google, note if the AI box cites us).
3. Score each cell: `✔ cited` (we're named/linked) · `~ mentioned` (facts from
   our pages, no attribution) · `✘ absent` · `⚠ wrong` (engine says something
   false about us — fix at the source page, then note it).
4. Leading indicator first: **admin → Analytics → bot hits** — log the month's
   GPTBot / ClaudeBot / PerplexityBot crawl counts. Crawl volume precedes
   citations; if a bot never crawls, don't expect its engine to cite.

**Questions (short keys — full wording & owner in keyword-map.md):**
